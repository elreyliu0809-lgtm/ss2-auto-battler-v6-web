# 少年演武 · V6 网页发行

Play: https://elreyliu0809-lgtm.github.io/ss2-auto-battler-v6-web/

Frozen game content: 苍金30武将（六阶各5）、旧18兼容包、9军需、10胜终局。V7/V8及48人计划未纳入此版本。浏览器代码来自便携V6 ZIP，SHA256 `c7d2174906f8cd676640834f812311794749261d940b1faef603a750873a114a`。网页不包含Windows Node运行时。

## 使用

首次打开需要下载约53MB离线资源；顶部显示下载进度，完成后显示“离线资源已就绪”。同一浏览器、同一网址再次打开，未变化的大资源从本机缓存读取。缓存被用户清除或被浏览器回收时需要重新下载。首次下载未完成时请联网重开，已校验部分会复用。

存档仅在当前浏览器保存；从旧localhost版本迁移需要先“导出存档”，再到此网页“导入存档”。不同设备/域名不会自动同步。新版先下载并校验完整，当前整局绑定原发行版；整局结束或空白新局时才允许点击切换。保留上一版可回退，更新不清存档。

## 出战记录和镜像

“出战记录 / 镜像”可查看、关闭、导出、删除本机记录。只记录游戏字段与随机去重ID，不记录昵称、邮箱或设备ID。战前0–9胜与战后累计胜数分开；终局不会伪造下一场出战。最近最多500场。

导入阵容先做版本、角色、数值、长度校验与去重，进入候选；玩家选择采用后才进入本机镜像库。镜像默认关闭；开启后同包同规则，优先同胜数，不足再±1，同时约束回合、生命与战力。固定池版本与种子可复现；无样本时回退V6原本地敌阵。镜像是异步阵容抽样，提交真实性未核验，不是实时真人或防作弊服务。

网页默认不上传。勾选公开同意后可打开GitHub Issue入口，玩家需自己登录、附上导出的JSON并提交。打开入口不等于上传成功。Pages没有匿名写入接口；本版本没有集中自动收集后端，也没有已审核公共玩家池。Issue附件不会自动成为正式敌阵。

维护者可先把附件下载到隔离目录，再执行 `node tools/validate-lineups.mjs input.json new-quarantine.json`。工具只输出已校验候选；仍需人工审核、版本冻结、单独发布与实际出战验证。不执行上传内容中的任何代码。

## 文件与更新

- `docs/`：Pages静态发布目录；`release.json`列出本发行版全部对象、长度与SHA256。
- `web/`：稳定加载器、Service Worker、本机阵容功能源码。
- `tools/build.mjs`：消费核验过的V6浏览器输入，生成 `public/`；`SS2_FROZEN_INPUT`可指定输入目录。源ZIP不在此仓库。
- `tools/qa.mjs`、`tools/regression.mjs`：需要本机已有Playwright/V6输入的作者验证脚本；不自动安装。
- `evidence/actor-equivalence.json`：30角色拆分重构校验与原纹理哈希。

新内容开发轨先交付冻结ZIP与SHA/内容规则版本，发布轨在隔离目录适配、验证再发布。不要从开发中的src直接覆盖此发行版。资源地址由内容哈希决定；仅代码变化不重下角色资源。更新发行编号不得复用已有编号改写不同字节。维护者保留旧发行对象/清单，以便缓存回退；清理须另做精确保留检查。

本项目使用已适配的少三2素材；未将素材权利转授为开源资产许可证。游戏为独立适配实现，不是SAP原版完整规则或官方联网服务。原有行为和素材限制见 `KNOWN-DIFFERENCES.md`。
